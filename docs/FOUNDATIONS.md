# Foundations

What Plumemu is for. When two rules pull against each other, these decide.

## F1. A launcher for handhelds, nothing else

Plumemu lists games and opens them in the emulators the person already has. It does not emulate,
does not ship games or BIOS files, and never links to where to get them.

## F2. Two minutes to the first game

From the end of installing to pressing a game: under two minutes, with no typing unless the
person wants box art, and no account required. Anything that adds a question to setup has to
earn it.

## F3. Light

Opens at once, scrolls ten thousand games without a dropped frame, does nothing heavy before the
first screen is up. Speed is measured, not assumed.

## F4. Minimal by default, deep when asked

The defaults are good enough to never open Settings. Everything a player could want to adjust is
there, out of the way, and can be set per system where it makes sense.

## F5. Buttons and touch are equals

Every handheld has both. Anything that can be done with a button can be done with a finger, and
the reverse. No screen works only one way.

## F6. Type is the look

The app has little decoration; the Plum fonts carry the design. Each font is tuned so it reads
well at handheld size, on whatever background the person picks.

## F7. One reference device, every shape

The design is drawn at the true size of the Retroid Pocket 5 (768×432 dp) and must hold from
4:3 screens (Retroid Pocket Nova, 576×432 dp) to wide 6-inch screens (AYN Thor, about 837 dp).
Text keeps its size; a wider screen shows more, a narrower one slides.

## F8. Free core

The library, launching, list and grid, fonts, themes and box art are free for good. If Plumemu
is ever sold, only extras are paid.

## F9. English first, every language possible

The interface is written in English and every word lives in a translation file, so any language
can be added without touching code.
