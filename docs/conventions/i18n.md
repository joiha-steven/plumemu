# Translations

- Every word a person sees lives in `res/values/strings.xml` (English, the master) of the module
  that shows it. No text in Kotlin or Compose code; the guard in `verify.sh` fails on literals in
  `Text(...)` and similar.
- Translations are `res/values-<lang>/strings.xml` with the same keys. The translations guard
  (`scripts/guards/translations.py`) fails on a missing or extra key, a placeholder or plural
  mismatch and text not in NFC. What translators need (voice, glossary, length budget, fonts,
  Chinese folders, texts outside strings.xml): [translation.md](translation.md).
- Keys name the place and meaning: `library_empty_title`, `setup_folder_found_files`. Plurals use
  `<plurals>`; numbers and dates are formatted with the locale, never concatenated by hand.
- Text must fit when it grows: German and Vietnamese run longer than English; layouts allow two
  lines where a label might wrap and cut with an ellipsis elsewhere.
- Letters outside English are allowed only in `values-*/` translation folders; the English-only
  guard enforces it.
- The person picks the app language in Settings › Advanced › Language (translation.md › Choosing a
  language): Android's per-app language from Android 13, a wrapped context before.
