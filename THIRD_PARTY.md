# Third-party material

Fonts, libraries and data inside the Plumemu app, with their licences. The same list, with the
full licence texts, is in the app under Settings › About › Open-source licenses. Updated with each
release; this list matches 0.0.2-alpha.

| What | Licence |
|---|---|
| Plum Sans, Plum Serif, Plum Mono (drawn from Inter, Literata and JetBrains Mono) | SIL Open Font License 1.1 |
| Jetpack Compose, AndroidX libraries (Activity, Room, SQLite, DataStore and their dependencies) | Apache License 2.0 |
| Kotlin standard library, kotlinx.coroutines, kotlinx.serialization | Apache License 2.0 |
| Coil (box art decoding), OkHttp and Okio | Apache License 2.0 |
| Protocol Buffers (repackaged inside AndroidX DataStore) | BSD 3-Clause |
| Platform and emulator definitions, from Daijishō | MIT |
| System and emulator rules for Android, from ES-DE | MIT |
| Arcade game names, years and makers, from MAME's `-listxml` output (BSD-3-Clause drivers only) | BSD 3-Clause |
| Console game titles and checksums, from MAME's software lists | CC0 1.0 (public domain) |
| Old arcade set names (MAME 2003-Plus) matched to current MAME sets | Facts only; no MAME 2003-Plus text is included |
| Cartridge game titles, regions and checksums, from [No-Intro](https://no-intro.org) | Used in alpha builds; permission asked before the first full release |
| Disc game titles, regions and serial codes, from [Redump](http://redump.org) | Used in alpha builds; permission asked before the first full release |
| GameCube, Wii, DS and 3DS titles, from [GameTDB](https://www.gametdb.com) | Used with a link to GameTDB, as its FAQ asks |
| Nintendo Switch titles, from blawar/titledb | MIT |
| LZMA SDK decoder by Igor Pavlov, ported to Kotlin | Public domain |

"MAME" is a trademark of Gregory Ember; Plumemu is not affiliated with the MAME project. Box art
and game details are not inside the app: they come from [ScreenScraper](https://www.screenscraper.fr)
with your own account, under ScreenScraper's terms.
