# Plumemu

A launcher for Android retro handhelds: your games in one calm list, set up in two minutes, and
light on the hardware.

> **Status: alpha, not released yet.** Test builds will appear under
> [Releases](../../releases), marked as pre-releases. Expect rough edges.

This repository holds Plumemu's releases, its issue tracker and its public documents. Plumemu is
not open source; the source code is not published here.

## What it does

- **Two-minute setup.** Pick your ROMs folder in Android's own folder picker. Plumemu never asks
  for access to all your files.
- **Emulators picked for you.** It finds the emulators already installed and picks one for each
  system; systems without one are named before a launch fails.
- **One sliding view** of systems, games and details, as a text list or a cover grid, laid out
  for 16:9 and 4:3 handheld screens.
- **Buttons and touch** work equally.
- **Your colours.** Pick a background, light or dark text, and an accent.
- **Light on the hardware.** No background service, nothing running while it sits idle, built
  for weak devices and old Android versions.

Planned after the first alpha: box art and game info from ScreenScraper with your own account,
more languages.

## Devices

Android 6.0 or later. Made for handheld screens from 4.5 to 6 inches; tested first on the AYN
Thor (upper screen). Plumemu uses one screen.

## Install

1. Download the `.apk` file from the latest release under [Releases](../../releases).
2. Open it on the device and allow your browser or file manager to install apps when Android
   asks.
3. Open Plumemu. To make it the home screen, press Home and choose Plumemu.

## What Plumemu does not include

No games, BIOS files, keys, firmware or emulators. Use files you own legally; emulators come
from their own developers.

## Feedback
