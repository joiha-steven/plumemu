# app

The Android application: one Activity, navigation and wiring of the feature modules.

It shows first-run setup until it is completed, then the main screen (the no-art list of the
alpha) with the library's content, in the stored theme, once the home screen question, and
Settings (Appearance, Advanced, About, Library, Emulators, Controls and Home screen).
Grid view and details are built but hidden until box art arrives.

Application id and namespace: `com.plumemu`.
